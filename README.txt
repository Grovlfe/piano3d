============================================================
  3D 钢琴演奏台 · VSL Steinway D-274
============================================================

【如何启动】
1. 双击本文件夹内的  start.bat
2. 浏览器会自动打开 http://127.0.0.1:8765
   （请使用 Chrome / Edge，需要支持 WebGL 与 Web MIDI）

无需联网，所有文件都在本地。

【功能一览】
· 3D 施坦威三角钢琴（使用你提供的 GLB 模型），88 个独立琴键
· 琴键物理动画：按下下移、按住保持、松开弹起；力度影响下压深度
· 默认音源：你提供的 "STEINWAY & SONS D-274 VSL.sf2"（2.6GB）
  已预先转换为浏览器采样包 soundfont/default/（启动即用）
· 外接 MIDI 键盘：即插即用，力度 0-127、三踏板 CC64/66/67、弯音
· 三踏板：
    左=柔音（键盘整体左移 + 音色变柔）
    中=持续音（只延住踩下瞬间按住的音）
    右=延音（模拟延音踏板，参考 Synthesia/BASSMIDI 效果）
· MIDI 文件 / 文件夹导入，播放列表、变速、进度跳转
· 导入任意 SF2 音源（内置解析器，支持大文件，自动降采样）
· 鼠标/触摸弹奏：点击发声，按住横向滑动 = 刮奏
· 电脑键盘弹奏：Z X C V B N M 白键，S D G H J 黑键，Q…P 高八度
· 光影：环境预反射 + 镜面衰减地板反射 + 自适应画质（60FPS 目标，
  最低 30FPS 保护，画质自动升降）
· 画质档位：极致（2K 渲染/高清阴影/瓷砖镜面反射/写实光照）、
  高、中、极限（流畅优先）
· 白色瓷砖地面：极致模式下瓷砖按光滑程度做镜面反射（带衰减）
· 立体声输出（按琴键位置声像），卷积混响

【公网访问（让其他人也能打开）】
方式一 · 免费临时公网网址（无需账号，推荐试玩）
  1. 双击 start_public.bat
  2. 等待出现 "https://xxxx.trycloudflare.com" 字样
  3. 把该网址发给任何人即可访问（微信/QQ 都能打开）
  注意：临时网址在电脑关机或隧道关闭后失效，重启后会变化。
       首次打开加载模型与音源约需要一些时间（资源较大）。

方式二 · 固定域名（正式发布，需要域名）
  1. 购买一个域名（阿里云/腾讯云，约 30-60 元/年）
  2. 注册 Cloudflare 账号（免费）并添加该域名
  3. 用 cloudflared.exe 登录并创建命名隧道（named tunnel），
     把域名 CNAME 指向隧道，即可获得固定网址
  4. 具体步骤见 Cloudflare 官方文档：
     https://developers.cloudflare.com/cloudflare-one/connections/connect-apps

方式三 · 部署到云服务器（带宽充足、速度最快）
  把整个文件夹上传到云服务器（需 Node 或 Python），运行 serve.py，
  再用 Nginx 反代 8765 端口并绑定域名（国内服务器需 ICP 备案）。

【音源说明】
- 默认启动即加载 soundfont/default/（由你的 VSL SF2 转换而来，
  每个键 3-4 个力度层，44.1kHz）。
- 想重新使用原始 SF2：点「导入 SF2 音源」选择
  I:\BassMidiVsti_x64\STEINWAY & SONS D-274 VSL.sf2 即可
  （2.6GB，解析约 1-3 分钟）。
- 如未加载任何音源，自动使用内置合成钢琴兜底。

【MIDI 外设提示】
- 若设备未显示：在系统里确认设备已连接，然后点「重新检测」。
- 演奏通道无限制，所有通道都会发声。

【故障排查】
- 页面空白/报错：确认通过 start.bat 启动（不要直接双击 index.html，
  浏览器禁止本地文件读取）。
- 音源不发声：确认页面顶部「音源」状态为 VSL D-274 或 导入音源。
- 卡顿：画质选「低」；或在地址栏输入 chrome://gpu 查看硬件加速。
- 帧率：右上角实时显示 FPS；自动画质会在低于 30FPS 时降级。
